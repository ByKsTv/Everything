## Settings

1. `Got it!`.
1. `Plex Pass` -> `X`.
1. `Allow me to access my media outside my home` -> Off.
1. `Add Library` -> `Movies` -> `Language` -> `Hebrew` -> `Next` -> `Browse for media folder` -> `Add Library` -> `Next` -> `Done`.
1. [Optional Playback Data](https://www.plex.tv/about/privacy-legal/#you-have-the-right-to-limit-what-activity-data-is-sent-from-your-plex-media-server) -> `Send playback data to Plex` -> Off.
